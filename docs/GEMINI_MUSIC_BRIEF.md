# Gemini production brief — PULSE music pack (optional; coding does not wait for it)

Why: the trailer's music is about 129 BPM and C-centred but its rights/source are unknown, so it is not used. The game now derives melody notes per world, so tracks must be **harmonically simple and leave room for the melody**.

Deliver per world (3 worlds) one seamless gameplay loop plus the menu theme:
- Style: electronic / synthwave, dark and driving; bold arpeggiated bass, tight kick on every beat, clap/snare on 2 and 4, sparse hats. No dense lead melody (the game plays the lead).
- Exact tempos: World 1 **125 BPM**, World 2 **133 BPM**, World 3 **140 BPM**, menu **112 BPM**. Constant tempo, no tempo drift, no pickup bars or silence at the start or end of the loop file (the game aligns the file start to beat 1).
- Keys: World 1 **Bb major**, World 2 **D minor**, World 3 **A minor**; stay inside the pentatonic of that key for pads and bass (avoid chromatic passing notes). State the real key in the file name.
- Length: 32 bars loop (World 1: about 61 s, World 2: about 58 s, World 3: about 55 s), loop-seamless (checked by looping in an editor).
- Format: OGG Vorbis, stereo, 44.1 kHz, about −14 LUFS integrated, true peak ≤ −1 dBFS, plus a WAV master.
- Optional stems (drums / bass / pads) per world so the game can add layers with combo.
- Deliver a sheet with BPM, key, bar count, and rights/licence statement (original work, no samples of third-party recordings).
Acceptance: a producer can loop each file for 10 minutes without a click or a beat shift.
